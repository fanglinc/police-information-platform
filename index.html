从"看数据"到"分析数据" From Viewing Data to Analyzing Data

课时一我们学会了"看"——看到了时间、地点、设备、属性。 但"看"不足以击穿抗辩。我们必须跨越到"分析"——用数据自身的逻辑，让谎言无处藏身。 In Class Hour 1 we learned to “look”—at time, location, device, and attributes. But looking is not enough to break a defense. We must leap to “analysis”—using the data’s own logic to leave lies nowhere to hide.

🔐

第五维 · 哈希值 Dimension 5 · Hash Value

哈希值是数据的"数字指纹"。任何对数据的修改——哪怕只改一个字节—— 哈希值都会完全改变。 A hash is the “digital fingerprint” of data. Any modification—even a single byte—will completely change the hash.

击穿点：嫌疑人称照片被"转发"过。 若照片真的被转发/修改，哈希值必然改变；若哈希值与原始值一致，"转发"抗辩不攻自破。 Rebutting point: The suspect claims the photo was “forwarded.” If it really was forwarded or altered, the hash must change; if the hash matches the original, the “forwarded” defense collapses.
🔗

第六维 · 关联关系 Dimension 6 · Association

关联关系是数据与主体、其他证据之间的逻辑联系。 单一证据易被抗辩，多重关联则形成"证据闭环"。 Association refers to the logical links between the data, the person, and other evidence. A single item is easy to challenge; multiple links form an “evidence closure.”

击穿点：嫌疑人称"同事拍的"。 但系统日志显示解锁者为张某本人，生物识别记录印证——操作者非他莫属。 Rebutting point: The suspect says “a colleague took it.” But system logs show Zhang himself unlocked the phone, and biometric records confirm it—only he could have been the operator.

哈希值击穿"转发"谎言 Hash Value Breaks the “Forwarded” Lie

嫌疑人称照片是"同事转发给他的"。如果照片真的被转发/修改过，哈希值必然改变。 我们现场计算并比对，让数据自己说话。 The suspect says a colleague forwarded the photo. If it really was forwarded or altered, the hash must change. We compute and compare on site, letting the data speak.

📐 哈希值原理与本案应用Hash Principles and Application in This Case

{{bi('原理','Principle')}}

SHA-256 是一种单向哈希函数：输入任意数据，输出 64 位十六进制"指纹"。 雪崩效应——修改任意一个字符，哈希值完全改变。 SHA-256 is a one-way hash function: any input yields a 64-character hexadecimal “fingerprint.” The avalanche effect means changing even one character completely changes the hash.

{{bi('本案应用','Application in This Case')}}

若张某所称"照片被转发"为真，转发过程必然修改了文件 → 哈希值必然改变。 我们计算当前照片哈希值，与登记保存时的原始哈希值比对，真伪立判。 If Zhang’s claim were true, forwarding would have altered the file → the hash would have changed. We compute the current hash and compare it with the original hash recorded at preservation to determine authenticity.

从"登记保存"到"扣押"——惊险一跃 From Registration and Preservation to Seizure — The Perilous Leap

技术做完了，证据闭环了。但这还不够——法律程序必须同步跟上，否则技术做的一切都将归于无效。 这就是"程序正义"：技术解决"能不能证明"，法律决定"证明有没有效"。 The technical work is done and the evidence chain closed. But that is not enough—legal procedure must keep pace, or everything the technology achieved becomes void. This is procedural justice: technology answers “can it be proven,” while law decides “is the proof valid.”
